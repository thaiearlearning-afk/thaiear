Dynamic audio capability probe

Measures what this device can actually do, so the r17 encoding work is built on facts rather than my estimates. It downloads ~0.6 MB of real clips, stitches a genuine ~7-minute session, then encodes it every way this device supports and tests whether the result plays and seeks accurately. Takes under a minute. Nothing is saved except a temporary file for the native test.

Whether AudioEncoder will accept each codec. This is the question I could not answer from documentation — encoder codec support is far patchier than decoder support.

Real session — size & speed

Built from real ThaiEar clips with the default TE layout (2 Thai repeats, English at the end), so the audio-to-silence ratio matches a genuine session.

Playback & seek accuracy

The decisive test. Sentence-skip and snap scrubbing need exact seeking; WAV gives that for free, but a compressed stream without an index can seek approximately. A large error here rules a format out.

Native engine (app only)

Whether the app's ExoPlayer/Media3 engine can play and seek the encoded file — the format has to satisfy this as well as the browser.
