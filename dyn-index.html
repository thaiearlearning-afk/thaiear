Dynamic player test index

The test space's own front page, so downloads can be exercised the way the real index works. A dynamic download stores each sentence's clips, not a finished file — so a settings change re-stitches offline, and a session the OS evicts rebuilds itself instead of the download being gone. The clips take about a second; the mp3 itself is constructed the first time you open the topic, and then stored.

Tap a topic's circle to download, or a ✓ to remove — then pick an action.
